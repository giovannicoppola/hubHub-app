## Description (4000)

```
hubHub shows the numbers behind your open-source work: release downloads, open issues, stars, forks and watchers for every repository you own, with the change since the previous snapshot next to each one.

ALL YOUR REPOS IN ONE LIST
Each repository shows the counts you choose, each with its change since last time. Sort by downloads, by any other count, by name, or by biggest change. Filter down to only the repos that moved.

ISSUES, MOST FIRST
A separate tab lists only the repositories with open issues, most first, so you know where to look.

HISTORY, CHARTED
Tap a repository to see any of its five counts charted over time. The history builds up on your phone every day you open the app, and you can import years of it from the alfred-hubHub workflow for Alfred on the Mac.

COUNTED CORRECTLY
Downloads count every asset of every release, not just the first. Watchers are real watchers, not stars under another name.

YOUR NUMBERS STAY YOURS
hubHub reads the GitHub API with a personal access token that you create. The token is kept in the iPhone Keychain on this device only, and goes nowhere but api.github.com. There is no hubHub server, no account, no analytics, and nothing is collected.

TRY IT FIRST
Turn on sample data in Settings to explore the app with a made-up account before adding a token.

hubHub is an independent app and is not affiliated with GitHub, Inc.
```
